# 🌙 Memory Nap Tabs 3.0

Расширение Chrome (Manifest V3) для снижения расхода оперативной памяти: неактивные вкладки уходят в сон через `chrome.tabs.discard`, а формы, плееры и лонгриды остаются нетронутыми.

## Возможности

- **Мягкое автоусыпление** — `chrome.alarms` + реальное время простоя (`tab.lastAccessed` с собственным резервным трекингом через `storage.session`).
- **Защита данных** — перед усыплением страница проверяется во **всех фреймах**: несохранённые `input`/`textarea`/`select` (сравнение с `defaultValue`), `contenteditable`, выбранные файлы, играющие плееры (`!paused && currentTime > 0`), Picture-in-Picture, лонгриды.
- **Реальная системная RAM** — `chrome.system.memory` показывает свободную память; опциональный режим «усыплять только при нехватке RAM».
- **Менеджер вкладок** — поиск, фильтры, сортировка, множественный выбор, групповые действия и **отмена** закрытия/усыпления.
- **Сессии** — сохраняют порядок, закреплённые вкладки и структуру окон; восстанавливаются в отдельные окна.
- **Профили** — Агрессивный (3 мин), Баланс (20 мин), Чтение (45 мин + защита лонгридов), таймеры настраиваются.
- **Белый список** — нормализация доменов, поддомены, добавление из контекстного меню и попапа.
- **Статистика** — график за 7/30 дней, локальные даты, автоочистка истории старше 120 дней, экспорт/импорт JSON.
- **QoL** — бейдж спящих вкладок на иконке, три горячие клавиши, тёмная/светлая/системная тема, компактный режим, отключение анимаций.

## Что исправлено относительно версии 2.x

| Было | Стало |
| --- | --- |
| Ключи манифеста и строки с пробелами, `& &`, `= >` | Валидный JSON и ES-модули |
| `escapeHtml` не экранировал символы | DOM строится через `textContent`, `innerHTML` для данных не используется |
| Миграция `local → sync` затирала настройки при каждом обновлении | Одноразовая миграция по флагу + удаление legacy-ключей |
| `/^www./` съедал `wwwX` | Экранированная регулярка + валидация hostname |
| Нет `lastAccessed` → вкладка усыплялась сразу | Резервный трекинг простоя, консервативный отказ |
| Чёрный список URL пропускал `about:`, `view-source:`, Web Store | Белый список схем + `host_permissions` только `http/https` |
| Любой тег `<video>` блокировал сон | Проверка реального воспроизведения |
| Попап 620px не влезал в лимит Chrome | 420×596 с собственной прокруткой |
| Плоская(плохо работает) оценка 70 МБ на вкладку | Модель по типу страницы + честная пометка «≈» и реальная RAM |
| Сессия теряла окна и закрывала последнюю вкладку | Структура окон, подтверждение, отмена, защита от закрытия браузера |
| Активная вкладка усыплялась переключением на случайную | Соседняя вкладка, повторная проверка состояния перед `discard` |

## Установка

1. `chrome://extensions/` → режим разработчика.
2. «Загрузить распакованное расширение» → папка проекта.
3. Chrome 121+ (используется `tab.lastAccessed`).

## Демо-режим

`popup.html` и `options.html` открываются и вне браузера-расширения: `platform.js` подставляет движок с демонстрационными вкладками, storage и показаниями памяти. Вся логика (`engine.js`) при этом исполняется та же, что и в service worker.
